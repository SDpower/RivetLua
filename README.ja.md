# RivetLua

[English](README.md) | [繁體中文](README.zh-TW.md) | [한국어](README.ko.md) | 日本語

RivetLua は、ほかのアプリケーションへの組み込みを目的とした、純粋な Rust 製 Lua コンパイラと実行エンジンを開発する、初期開発段階の独立したオープンソースプロジェクトです。

親プロジェクト、アカウント、データベース、モデルサービス、システムの Lua、自動テレメトリ、バックグラウンドのネットワークアクセスには依存しません。

## 現在の状況

RivetLua は P11 までで検証済みの Lua サブセットをコンパイルして実行できます。P08～P11 の受け入れケースは Lua 5.5 と Lua 5.4 の両 profile で合格しています。Lua 全体との互換性と公開 Rust SDK は未完成です。

実装済みの機能、今後の作業、検証コマンドは[実装状況の一覧](docs/IMPLEMENTATION_STATUS.ja.md)をご覧ください。

## ビルド基準

開発にはシステム既定の Rust `stable` ツールチェーンを使用します。最小サポート Rust バージョン（MSRV）は `1.94.1` です。この基準の変更には互換性に関する判断が必要です。ビルドとテストのコマンドには `--locked` を使います。

## 開発方針

- Lua のソースコードまたは AST を検証済みのバイトコードにコンパイルし、仮想マシンで実行します。
- ホストアプリケーション向けの Rust SDK、リソース制御、オプションの実行機能を提供します。
- Lua との互換性を段階的に検証し、適したプラットフォームで JIT/AOT を評価します。
