# RivetLua

[English](README.md) | [繁體中文](README.zh-TW.md) | [한국어](README.ko.md) | 日本語

RivetLua は、ほかのアプリケーションへの組み込みを目的とした、純粋な Rust 製 Lua コンパイラと実行エンジンの開発を計画している独立したオープンソースプロジェクトです。

## 現在の状況

プロジェクトは現在、計画段階です。Rust SDK、実行エンジン、コマンドラインツールはまだ実装されておらず、互換性とテスト結果も検証されていません。

## 開発方針

- Lua のソースコードまたは AST を検証済みのバイトコードにコンパイルし、仮想マシンで実行します。
- ホストアプリケーション向けの Rust SDK、リソース制御、オプションの実行機能を提供します。
- Lua との互換性を段階的に検証し、適したプラットフォームで JIT/AOT を評価します。
