# RivetLua

[English](README.md) | [繁體中文](README.zh-TW.md) | 한국어 | [日本語](README.ja.md)

RivetLua는 다른 애플리케이션에 내장할 수 있는 순수 Rust 기반 Lua 컴파일러와 실행 엔진을 목표로 하는 초기 개발 단계의 독립적인 오픈 소스 프로젝트입니다.

이 프로젝트는 상위 프로젝트, 계정, 데이터베이스, 모델 서비스, 시스템 Lua, 자동 원격 측정 또는 백그라운드 네트워크 접근에 의존하지 않습니다.

## 현재 상태

Rust 워크스페이스, 공식 Lua 참조 자료, 테스트 실행기, 코어 값·숫자·오류를 처리하는 Rust API가 구현되어 있습니다. Rust SDK와 Lua 실행 엔진은 아직 구현되지 않았습니다. Lua 소스 실행과 언어 호환성은 검증되지 않았습니다.

구현된 기능, 남은 작업, 검증 명령은 [구현 현황 목록](docs/IMPLEMENTATION_STATUS.ko.md)을 참고하세요.

## 빌드 기준

개발에는 시스템 기본 Rust `stable` 도구 모음을 사용합니다. 최소 지원 Rust 버전(MSRV)은 `1.94.1`이며, 이 기준을 변경하려면 호환성 결정을 별도로 내려야 합니다. 빌드와 테스트 명령에는 `--locked`를 사용합니다.

## 개발 방향

- Lua 소스 코드 또는 AST를 검증된 바이트코드로 컴파일하고 가상 머신에서 실행합니다.
- 호스트 애플리케이션을 위한 Rust SDK, 리소스 제어 및 선택적 실행 기능을 제공합니다.
- Lua 호환성을 단계별로 검증하고 적합한 플랫폼에서 JIT/AOT를 평가합니다.
